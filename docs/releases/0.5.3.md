# Web Clipper 0.5.3

Released to browser stores on 2026-10-21 (Asia/Singapore).

## Source and validation

- Fix commit: `1661c300bf87180dd5336d6d8cd51de7a2bf0919`.
- Package source commit: `98a119abeeddeaa574aae6558cab8ffc223dcbf8`.
- Tools: Node.js 26.4.0; pinned pnpm 11.10.0.
- `pnpm lint`, 352 tests in 28 files, locale validation (240 messages in nine locales), TypeScript, production build, and `git diff --check` passed.
- All four ZIPs passed integrity and manifest checks. Manual Chromium retains its public identity key; store packages omit `key` and `update_url`. Chrome and Edge archives are identical. Firefox preserves `web-clipper@usememos.com` and uses `background.scripts`.
- Firefox `web-ext lint` and AMO validation: zero errors, five existing bundled-code `innerHTML` warnings.
- Firefox 152.0.6 runtime QA on the same implementation before the version-only release bump: reproduced the original HTTP failure, then verified HTTP confirmation, direct connection to an isolated real Memos 26.10.20 development server, private memo creation and exact server content, light/dark warning contrast (at least 4.5:1), narrow layouts, Chinese copy, and separate destructive styling for revoked-token errors.
- A clean reviewer build matched all 58 Firefox ZIP entries byte-for-byte. No source-code archive was uploaded, per the user's instruction. Reviewer notes contain only the change explanation and test instructions.
- Removed a generated `.DS_Store` from the packaging stage before the final archives were uploaded. The final packages exclude it.
