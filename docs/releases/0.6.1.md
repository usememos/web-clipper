# Web Clipper 0.6.1

Released to browser stores on 2026-11-01 (Asia/Singapore).

## Source and validation

- Release commit: `159b37d` (`chore(release): prepare version 0.6.1`), on top of `5d2b97f` (`feat(errors): explain usage-limit and rate-limit refusals from Memos 26.10`). Neither has been pushed.
- Package source commit: `159b37d`, with a clean tree.
- Tools: Node.js 26.4.0; pinned pnpm 11.10.0.
- `pnpm lint`, 390 tests in 29 files, locale validation (253 messages across 9 locales), TypeScript, production build, and `git diff --check` passed. The store-artwork workspace was not rebuilt because no artwork source changed (see Listing assets).
- All four ZIPs passed integrity and manifest checks. Manual Chromium retains its public identity key; store packages omit `key` and `update_url`. Chrome and Edge archives are identical. Firefox preserves `web-clipper@usememos.com` and uses `background.scripts`. Permissions are unchanged (storage, identity, contextMenus, activeTab, scripting; `https://*/*` and `http://*/*`). No archive contains `.DS_Store` or source maps.
- Firefox `web-ext lint` on the packaged archive and AMO upload validation: zero errors, seven bundled-code `innerHTML` warnings (0.6.0 had six; the updated bundled editor adds one).
- No packaged smoke test against a live Memos 26.10 instance was performed in this run. The quota and rate-limit handling is covered by unit tests for the client, the error copy, and the popup notice.
