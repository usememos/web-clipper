# Web Clipper 0.6.0

Released to browser stores on 2026-10-30 (Asia/Singapore).

## Source and validation

- Release commit: `e36c02db6990c3d013132e24b4d37148488f809d` (`chore(release): prepare version 0.6.0`).
- Package source commit: `2e01006da352d1c727cfae83eec0243d6fc13c2c`. It adds one packaging fix after the release commit: `.DS_Store` files are left out of the archives. Finder had written one into `dist/` during the first packaging run; those archives were discarded before any upload.
- Tools: Node.js 26.4.0; pinned pnpm 11.10.0.
- `pnpm lint`, 374 tests in 29 files, locale validation, TypeScript, production build, the store-artwork workspace checks, and `git diff --check` passed.
- All four ZIPs passed integrity and manifest checks. Manual Chromium retains its public identity key; store packages omit `key` and `update_url`. Chrome and Edge archives are identical. Firefox preserves `web-clipper@usememos.com` and uses `background.scripts`. No archive contains `.DS_Store` or source maps.
- Firefox `web-ext lint` and AMO upload validation: zero errors, six bundled-code `innerHTML` warnings (0.5.3 had five; the new bundled editor and design-system code add one).
- Packaged smoke test: the Chrome archive, loaded unpacked in headless Chrome, rendered the popup, settings, and saved-clips pages in light and dark from the system setting, with no page errors. No live Memos server save was performed in this run.
